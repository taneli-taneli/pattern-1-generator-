# Pattern Generator

This project is a visual pattern generator that creates animated tile patterns using JavaScript and the p5.js library. The generator allows users to interact with the tiles, creating unique designs with each mouse movement.

## Files Overview

- **generator.html**: Contains the HTML structure and elements necessary for the generator functionality.
- **script.js**: Handles the logic for the pattern generation, setting up the canvas, creating tiles, and managing their animations and interactions.
- **package.json**: Configuration file for npm, listing dependencies and scripts for the project.
- **README.md**: Documentation for the project, explaining its purpose, setup instructions, and usage details.

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the necessary dependencies by running:
   ```
   npm install
   ```
4. Open `generator.html` in a web browser to view and interact with the pattern generator.

## Usage

- The canvas displays a grid of animated tiles that respond to mouse movements.
- Click anywhere on the canvas to generate a new arrangement of tiles.
- The colors and rotations of the tiles change dynamically, creating a visually engaging experience.
